## 🚀 快速开始

```bash

# 开发模式
```

## 🎨 技术栈

- **框架**: React 19 + TypeScript
- **构建**: Vite 6
- **图表**: ECharts 5（柱状图、箱线图、雷达图、桑基图、热力图、仪表盘、饼图等）
- **样式**: Tailwind CSS 4（深色主题、自定义设计令牌）
- **动画**: GSAP（数字滚动、卡片入场、粒子背景）
- **粒子**: Canvas API（动态粒子连线背景）

## 🔑 数据洞察摘要

### 最大短板
- **公共教学用房**: 52.2% 学校不达标（446所），得分率仅 47.8%
- **生机比**: 34.9% 学校不达标（298所），得分率 65.1%

### 结构性矛盾
- 中高级职称教师比例达标率仅 76.8%
- 音体美专任教师达标率 86.9%
- 教职工编制达标率 84.4%

### 学校类型差异
- 九年制 > 初中 > 小学（均分：41.94 > 41.54 > 41.29）
- 小学在硬件与环境维度短板最突出

### 城乡差异
- 城市学校总体优于县镇和农村
- 部分指标城乡差异显著（如生机比、专用教室等）

### 可视化解读文档模板

**主题**: 基于义务教育标准化学校监测数据的多维度可视化分析看板

**应用场景**: 教育主管部门对辖区内义务教育学校标准化建设进行监测评估与决策支持

**数据说明**: 
- 数据来源：温州市教育局脱敏数据集
- 数据规模：855所学校 × 44项监测指标
- 数据维度：学校管理与安全（11分）、办学硬件与环境（20分）、师资队伍与发展（13分）
- 分类维度：办学类型（小学/初中/九年制）、城乡分组（城市/县镇/农村）

**核心亮点**:
1. 10种可视化组件：动画卡片、洞察面板、仪表盘、箱线图、雷达图、横向条形图、分组柱状图、桑基图、热力图、进度对比图
2. 深色科技主题：配合粒子连线背景，营造数据监控中心氛围
3. GSAP动画：数字滚动计数、卡片入场动画，提升视觉体验
4. 数据驱动洞察：5条关键发现直接嵌入看板，实现"看图说话"
5. 多维度交叉分析：学校类型 × 城乡分组 × 指标类别的三维分析体系

**教育故事**:
- 视角一：公共教学用房的"隐形危机"——超过一半学校未达标，制约素质教育发展
- 视角二：师资队伍的结构性短板——编制不足、职称偏低、音体美教师匮乏的三重困境
